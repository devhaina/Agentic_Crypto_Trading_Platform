# Glossary

Agent: Software component capable of reasoning over approved tools/data.
Trading Intent: Internal request to attempt a trade.
Trading Signal: Strategy-generated recommendation.
Risk Check: Deterministic evaluation of a proposed trade.
Execution: Exchange-facing order submission and lifecycle management.
Position: Current holding in an asset.
Exposure: Portfolio value allocated to an asset/market.
Reconciliation: Comparison of exchange state with internal state.
Idempotency: Repeated processing produces the same financial result.
Outbox: Durable event record written with the business transaction.
Market Candle: OHLCV data for a timeframe.
Paper Trading: Simulated trading using live/historical market data without real capital.
Kill Switch: Mechanism that prevents new trading.
Strategy Version: Immutable version of a strategy configuration/implementation.
Agent Run: One execution of an AI agent workflow.
